About Smart Contact Manager

Smart Contact Manager is a simple application to manage your contacts.

It allows you to add, edit, and delete contacts easily.

The application is built using Spring Boot and Thymeleaf, providing a modern web interface.

To get started, please log in or register a new account using the navigation menu.

If you have any questions or feedback, feel free to contact the support team.

Thank you for using Smart Contact Manager!
